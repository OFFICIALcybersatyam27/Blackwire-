# 🚀 BlackWire-SRY

**BlackWire-SRY** is a Python-based Android ADB toolkit designed for **device management, debugging, and authorized security research**.

---

# ✨ Features

- 📱 Device Detection
- 🖥️ Interactive ADB Shell
- 📸 Screenshot Capture
- 🎥 Screen Recording
- 📂 File Transfer
- 📦 APK Installation
- 🗑️ APK Uninstallation
- 📋 Package Listing
- 🔋 Battery Information
- 📜 Logcat Viewer
- 🌐 Network Information
- 🔁 Port Forwarding
- 📊 System Information
- 🎯 Launch Installed Applications
- 📡 Current Activity Information
- ⚙️ ADB Server Management

---

# 💻 Installation

## Linux

```bash
sudo apt install adb python3
git clone https://github.com/OFFICIALcybersatyam27/Blackwire-.git
cd Blackwire-
pip3 install colorama
python3 blackwire.py
```

## Windows

```powershell
git clone https://github.com/OFFICIALcybersatyam27/Blackwire-.git
cd Blackwire-
pip install colorama
python blackwire.py
```

## macOS

```bash
brew install android-platform-tools
git clone https://github.com/OFFICIALcybersatyam27/Blackwire-.git
cd Blackwire-
python3 -m pip install colorama
python3 blackwire.py
```

---

# 📌 Requirements

- Python 3.9+
- Android Platform Tools (ADB)
- USB Debugging enabled
